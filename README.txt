========================================
 OCRツール - 使い方 / How to Use
========================================

■ 起動方法
------------------------------------------

【Windows】
  start.bat をダブルクリックするだけです。
  自動的にブラウザが開き、ツールが起動します。

【Mac / Linux】
  ターミナルで以下を実行してください:
    chmod +x start.sh
    ./start.sh

【手動でHTTPサーバーを起動する場合】
  Python が入っている場合:
    python -m http.server 8765
  Node.js が入っている場合:
    npx serve -p 8765

  起動後、ブラウザで http://localhost:8765/ocrtool.html を開いてください。


■ 必要なもの
------------------------------------------
  - Python 3 (推奨)  https://www.python.org/
    または
  - Node.js          https://nodejs.org/
    または
  - Ruby (macOS標準搭載)

  ※ インターネット接続が必要です（初回OCR時に言語モデルをダウンロードします）
     日本語モデル: 約10MB
     英語モデル  : 約13MB


■ なぜダブルクリックでは動かないの？
------------------------------------------
  ブラウザのセキュリティ制限により、file:// で直接開くと
  OCRエンジン（Web Worker / WASM）がブロックされます。
  HTTPサーバー経由で開くことで制限が回避されます。


■ 機能一覧
------------------------------------------
  ・複数画像の一括OCR処理
  ・範囲指定OCR（最大100範囲）
  ・範囲ごとにCSV出力列を指定
  ・日本語・英語・中国語など10言語対応
  ・画像前処理（二値化・コントラスト・シャープネス）
  ・CSV出力（UTF-8 BOM / Shift-JIS 対応）
  ・結果の手動編集
  ・外部APIなし・データは外部送信されません
